# Investor Deck Archetype Checklist

Benchmark source:
- `AGEH_7GI_Tuesday_Second_Pass_2026-06-20.pptx`

Use this checklist when reviewing a client-facing investor, advisory, or PE-style
deck before sign-off.

## Deck-Level Checks

- [ ] The deck uses a consistent page family rather than a sequence of unrelated layouts
- [ ] Main-body slides have one dominant gesture each
- [ ] Titles read like takeaways, not file names or topics
- [ ] Chrome is consistent: logo placement, top rule, footer, page number behavior
- [ ] Main-body slides that combine multiple elements often end with a synthesis strip
- [ ] Appendix slides still look like part of the same designed system

## Recommended Slide Families

- [ ] `cover_hero_photo_left_text_block` for the opening page
- [ ] `thesis_three_pillar_cards` for 3 parallel strategic reasons
- [ ] `numbered_horizontal_proposition_rail` for multi-step strategy or proposition pages
- [ ] `executive_bio_cards_centered` for team / access / credibility pages
- [ ] `firepower_two_zone_summary` for capital, value-creation, or size-of-prize pages
- [ ] `three_route_opportunity_triage` for opportunity-bucket pages
- [ ] `pipeline_evidence_table` for high-graded pipeline pages
- [ ] `market_map_reference_exhibit` when an existing asset map is stronger than a rebuild
- [ ] `programme_day_cards` for reverse roadshow or multi-day programmes
- [ ] `banker_vertical_process_spine` for M&A timelines and approval choreography
- [ ] `appendix_ranked_table_card` for ranking pages
- [ ] `appendix_workstream_icon_cards` for workstream or diligence appendix pages

## Page-Quality Checks

- [ ] Each slide has a clear place for the eye to start
- [ ] Cards use repeated grammar: header band, badge/icon, calm body, consistent shadow
- [ ] Body copy is short enough that the layout still reads as an infographic
- [ ] Dense pages are zoned into anchor object, metrics, route, and notes
- [ ] Methodology and caveats are handled in a strip, not scattered across the page
- [ ] Arrows, spines, or rails are used when the page is about sequence
- [ ] Repetition is deliberate: motifs recur across slides without feeling templated

## Fast Fail Questions

- [ ] Would a human analyst keep this slide as-is, or immediately rebuild it?
- [ ] Can the core message be understood in 5 seconds?
- [ ] If the slide has three or more boxes, is there a stronger archetype than "boxes on a page"?
- [ ] If the page is dense, is the density controlled and readable?
- [ ] Does the slide end on a message rather than merely on content?
